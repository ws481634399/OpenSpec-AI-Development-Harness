# 4. 前端开发原则


## 4.1 组件化优先


前端功能应该通过组件组合实现。


要求：

- 单个组件职责明确；
- 避免超大组件；
- 提升复用能力。


---

## 4.2 类型安全


优先使用类型约束。


例如：

推荐：

```
TypeScript Interface

Type Definition
```


避免：

```
any
```


大量扩散。


---

## 4.3 数据与展示分离


页面组件不应该承担所有业务逻辑。


推荐：


```
页面组件

↓

业务逻辑层

↓

数据访问层
```

# 7. 禁止行为


AI 和开发人员禁止：


## 7.1 无规划增加组件


避免：

- 重复组件；
- 无意义封装；
- 随意增加目录。


---

## 7.2 绕过已有状态管理


禁止：

- 在多个地方重复维护同一状态；
- 随意新增全局变量。


---

## 7.3 修改公共组件不验证影响


公共组件修改需要评估：

- 使用范围；
- 影响页面；
- 回归风险。
