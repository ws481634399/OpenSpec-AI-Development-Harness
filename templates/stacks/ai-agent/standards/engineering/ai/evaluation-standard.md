# AI评估规范

> 版本：v0.1  
> 类型：AI工程规范  
> 作用域：OpenSpec Workspace


# 1. 文档目的


本文档定义 AI 应用能力的评估、测试和持续优化规范。


目标：

- 保证 AI 输出质量；
- 验证 Agent 执行效果；
- 建立 AI 能力测试体系；
- 支持 AI 应用持续优化；
- 指导 AI Coding Agent 进行结果验证。


AI评估用于验证：

```
模型能力

+

Prompt设计

+

Agent流程

+

Tool调用

+

知识使用

↓

最终业务效果
```


---

# 2. AI评估原则


## 2.1 结果可验证


AI输出不能只依赖人工感觉。


应该通过：

- 明确标准；
- 测试案例；
- 评价指标；
- 对比结果。


进行验证。


---

## 2.2 评估关注业务价值


AI能力评估应该关注：

- 是否解决问题；
- 是否提高效率；
- 是否降低成本；
- 是否提升质量。


而不是单纯关注模型能力。


---

## 2.3 持续优化


AI系统应该持续迭代。


流程：

```
发现问题

↓

分析原因

↓

优化Prompt / Agent / Tool / Knowledge

↓

重新评估

↓

版本更新
```


---

# 3. AI评估对象


AI评估主要包括：


```
Prompt评估

Agent评估

Tool评估

Knowledge评估

整体效果评估
```


---

# 4. Prompt评估规范


## 4.1 评估目标


验证 Prompt 是否能够稳定完成目标任务。


关注：

- 输出准确性；
- 输出完整性；
- 输出格式稳定性；
- 边界情况处理。


---

## 4.2 Prompt测试案例


Prompt应该包含测试案例。


例如：


```
输入：

用户需求描述


期望输出：

需求分析结果
```


---

## 4.3 Prompt评估指标


包括：


|指标|说明|
|-|-|
|准确性|结果是否正确|
|完整性|是否覆盖要求|
|稳定性|多次执行是否一致|
|可控性|是否遵守约束|


---

# 5. Agent评估规范


## 5.1 Agent评估目标


验证 Agent 是否能够正确完成任务流程。


关注：

- 任务理解；
- Workflow执行；
- Tool选择；
- 状态管理；
- 异常处理。


---

## 5.2 Agent测试场景


应该覆盖：


## 正常流程


例如：

```
输入需求

↓

Agent分析

↓

生成结果
```


---

## 异常流程


例如：

```
缺少上下文

↓

Agent识别问题

↓

请求补充信息
```


---

## 边界流程


例如：

```
复杂任务

↓

Agent拆解执行
```


---

# 6. Tool评估规范


## 6.1 Tool评估目标


验证 Tool 是否：

- 能正确执行；
- 返回稳定结果；
- 处理异常。


---

## 6.2 Tool测试内容


包括：


输入测试：

```
参数正确

参数缺失

非法参数
```


结果测试：

```
成功返回

业务失败

系统异常
```


---

## 6.3 Tool安全评估


检查：

- 权限控制；
- 数据保护；
- 参数限制。


---

# 7. Knowledge评估规范


## 7.1 知识准确性


检查：

- 来源是否可靠；
- 内容是否有效；
- 是否过期。


---

## 7.2 知识召回效果


如果使用 RAG：

评估：

- 是否找到正确知识；
- 是否遗漏关键内容；
- 是否返回无关内容。


---

## 7.3 知识一致性


检查：

不同知识之间是否存在：

- 冲突；
- 重复；
- 过期内容。


---

# 8. AI输出质量评估


AI输出应该从多个维度评价。


## 正确性


是否符合：

- 事实；
- 项目规则；
- 业务要求。


---

## 完整性


是否包含：

- 必要信息；
- 必要步骤；
- 风险说明。


---

## 可执行性


输出是否能够：

- 指导开发；
- 指导操作；
- 产生实际结果。


---

## 稳定性


相同输入：

是否能够产生接近结果。


---

# 9. 评估数据管理


评估数据应该保存。


推荐结构：


```
evaluation/

├── datasets/

├── cases/

├── results/

└── reports/
```


---

## 9.1 测试案例


记录：

- 输入；
- 上下文；
- 期望结果。


---

## 9.2 测试结果


记录：

- 执行时间；
- 使用模型；
- 版本；
- 输出结果。


---

## 9.3 评估报告


记录：

- 评估结论；
- 问题；
- 优化建议。


---

# 10. AI版本管理


AI能力需要版本管理。


包括：

- Prompt版本；
- Agent版本；
- Tool版本；
- Knowledge版本。


版本格式：


```
Major.Minor.Patch
```


---

# 11. AI Coding Agent验证规则


AI Coding Agent 完成任务后必须：


执行：

```
Implementation

↓

Validation

↓

Evidence
```


输出：

- 修改内容；
- 测试结果；
- 风险说明。


---

AI 不应该：


## 11.1 未验证声明完成


禁止：

没有执行验证却说明：

```
任务完成
```


---

## 11.2 忽略失败结果


失败应该：

- 记录；
- 分析；
- 修复。
