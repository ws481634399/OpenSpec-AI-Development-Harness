# sdd-task Checklist

## 1. 元信息

- [ ] Change ID / Design 来源 / 状态流转（designed → tasked）正确

## 2. 任务质量

- [ ] 每个任务都有 目标仓库 / 目标模块 / 预期变更 / 验证方法 四项
- [ ] 任务粒度：每个任务可在 ≤1 个提交内完成（不超边界）
- [ ] 没有遗漏 design.md 中的每个修改点（至少 1:1 对应）

## 3. 可验证性

- [ ] 每个任务的"验证方法"都是可操作的（不是"测试一下"）
- [ ] 不依赖无法单独执行的全局前提

## 4. 状态推进

- [ ] status 已到 tasked
